Before posting, re-run the README quick start in a clean repository and check
the current rules of the target community. Do not post identical copy across
communities or imply adoption that has not happened.

## Website decision

Do not add GitHub Pages yet. The README already provides the installation,
Action workflow, real output, security model, and contribution path at the
canonical repository URL. A second landing page would duplicate content and add
maintenance before there is evidence that it improves onboarding.
