# MergeReceipt roadmap

This roadmap describes direction, not promised dates. Deterministic evidence
remains the product core; optional semantic judgment stays secondary.

## Now

- Stabilize the v0.1 configuration, report, and exit-code contracts.
- Exercise MergeReceipt in varied real-world repositories and pull requests.
- Remove onboarding friction and improve task-oriented documentation.
- Verify Node.js, git, shell, and filesystem compatibility across platforms.

## Next

- Add richer deterministic signals where they have reproducible inputs.
- Improve terminal, JSON, and GitHub Summary reporting.
- Support clearer configurable policies without hiding verdict rules.
- Improve source-to-test relationships for common monorepo layouts.

## Later

- Add optional provider-neutral semantic review adapters.
- Explore Codex, Claude, and other coding-agent integrations without making any
  provider mandatory.
- Compare pull request claims with deterministic evidence as an advisory signal.

Semantic output will not replace build, test, lint, typecheck, or human review.
